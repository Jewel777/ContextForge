# Contributing to ContextForge

Thanks for your interest in improving ContextForge.

ContextForge is currently a **public beta with a private source repository**. The public GitHub repository is primarily used for releases, documentation, bug reports, and feature feedback.

## How You Can Contribute

You can help by:

- reporting reproducible bugs
- suggesting features or workflow improvements
- reporting documentation problems
- testing releases on supported platforms
- sharing usability feedback
- reporting security issues privately

## Bug Reports

Please use the **Bug Report** issue template and include:

- ContextForge version
- operating system
- steps to reproduce
- expected behavior
- actual behavior
- relevant logs or screenshots

## Feature Requests

Use the **Feature Request** template to describe:

- the problem or use case
- the proposed behavior
- why the feature would improve ContextForge

## Security Issues

Do not report security vulnerabilities publicly.

Please follow the instructions in:

```text
SECURITY.md
```

## Source Code

The ContextForge application source code is currently maintained in a private repository.

Public source contributions are therefore not currently accepted.

Documentation corrections, bug reports, testing feedback, and feature suggestions are welcome through this repository.

## Feedback

ContextForge is still evolving, and practical feedback from real workflows is especially valuable.

Thank you for helping improve ContextForge.
