# ContextForge Roadmap

ContextForge is currently in public beta. The roadmap below reflects the current development direction and may evolve based on testing and user feedback.

## Current — v2.1

- Windows x64 release
- macOS Apple Silicon release
- Local-first processing
- Evidence-aware context compilation
- Context Inspector
- Standard and Advanced modes
- Hierarchical retrieval
- Token-budget-aware output
- Source traceability
- Diagnostic logging

## Near Term

- Improve packaging and first-launch experience
- Apple code signing and notarization
- Additional retrieval diagnostics
- Expanded explainability and trust indicators
- Performance and memory optimizations
- Better large-document handling
- UI and workflow refinements based on beta feedback

## Planned Platform Support

- macOS Intel
- Linux

## Longer Term

- Additional context compilation strategies
- Improved evidence prioritization
- More export and model-handoff formats
- Expanded retrieval controls
- Research-oriented evaluation tooling
- Broader integration options

## Feedback

Roadmap priorities may change based on real-world usage.

Feature suggestions are welcome through GitHub Issues and Discussions.
